# Lil Ron’s Pizza

Coming-soon site for **Lil Ron’s** — NY / NJ thin crust landing in Northeast Seattle.

**Thin crust. Thick accent.**

## What’s here

- Home, menu, Ron’s story, and pre-order pickup
- Classic plain by the slice or the pie
- Pre-order form (no payment yet) stored in Postgres
- Glossy early-web diner look

## Local

```bash
npm install
npm run dev
```

Then open the app in your browser. The dev server binds to port 8080.

```bash
npm run typecheck
npm run build
```

## Stack

React 19, TanStack Start, Tailwind v4, Vite, Postgres (Neon in production, PGLite in preview).

## Notes

Address, hours, Instagram, and prices are still TBA. Pre-orders collect name, email, slice-or-pie, and a note for Ron.
